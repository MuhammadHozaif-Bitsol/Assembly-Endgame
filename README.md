# Assembly: Endgame 🎮

A word-guessing game built with React where players guess hidden words to save programming languages from being replaced by Assembly.

## Features

- **Word Guessing Logic:** Interactive on-screen keyboard to guess letters.
- **Dynamic Farewells:** Triggers custom farewell messages each time a wrong guess "eliminates" a programming language.
- **Visual Feedback:** Tracks guess accuracy with dynamically styled keyboard keys and language status chips.
- **Game State Handling:** Win and lose conditions reveal the full word and display game status updates.

## Tech Stack

- **React** (`useState`, `startTransition`)
- **clsx** (Conditional CSS class management)
- **CSS Modules / Plain CSS** (`App.css`)
